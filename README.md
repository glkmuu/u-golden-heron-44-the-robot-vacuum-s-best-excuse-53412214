# The Robot Vacuum's Best Excuse

The funniest one-line excuse a robot vacuum gives for missing a spot, for the
make.fun competition `u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214`.

> My cliff sensor mistook your rug fringe for a staircase, so I filed that corner as certain death and retreated to my dock.

122 characters, one line, inside the 1–140 character gate.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) reads `entry.txt`, validates
the gate (UTF-8, one line, 1–140 characters, not only whitespace) and writes
it byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Files

- `main.py` — entry program (Python 3.13, stdlib only)
- `entry.txt` — the entry, one line, 122 characters
